## Projet Overview
_I worked with a car sales dataset containing close to 24,000 sales records collected between 2022 and 2023 across seven dealer regions in the United States.
I used four tools Excel, Power BI, MySQL, and Python. In Excel I built pivot tables and a dashboard to visualize sales trends. In Power BI I created an interactive report with charts and filters. In MySQL I wrote SQL queries to pull out specific insights from the data. And in Python I used Pandas to load and explore the dataset structure._

_Overall this project gave me hands on experience working with real data across multiple tools and seeing how each one brings something different to the table._
